Glosario Clave de Rust y Redes

Conceptos fundamentales utilizados en este proyecto explicados amigablemente

Arc<T> (Atomically Reference Counted)

Puntero de conteo de referencias atómico. Permite compartir la propiedad de un valor entre múltiples hilos de forma segura sin provocar carreras de datos (data races).

Mutex<T> (Mutual Exclusion)

Garantiza exclusión mutua. Solo un hilo a la vez puede acceder a los datos internos envueltos por el Mutex pidiendo un "candado" (lock).

mpsc::channel() (Multi-Producer, Single-Consumer)

Canal de comunicación donde varios transmisores (`Sender`) envían tareas y un único receptor (`Receiver`) las procesa en cola FIFO.

TcpListener & TcpStream

Componentes de red de la librería estándar de Rust (`std::net`). `TcpListener` escucha en la IP y puerto especificados, mientras que `TcpStream` representa la conexión cliente-servidor abierta.

Directory Traversal Attack

Vulnerabilidad donde un atacante solicita rutas con `../` para intentar acceder a archivos confidenciales del sistema operativo. Se soluciona verificando que la ruta resultante comience con el directorio estático autorizado (`starts_with`).
